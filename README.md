Entry for [The Robot Pickup Line Championship](https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b) on make.fun.

`main.py` (Python 3, stdlib only, no network) writes one pickup line — a robot
reading its own error logs — to `entry.txt`. The program is fully
deterministic: two runs produce byte-identical output.

Run it:

```sh
ENTRY_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
